# Example Module

Dummy-Modul, das den Module Slot Contract demonstriert.

## Zweck

Zeigt, wie ein Modul korrekt aufgebaut wird:
- `module.json` mit allen Pflichtfeldern
- `README.md` mit Dokumentation
- `src/` mit (hier minimalem) Quellcode

## Verhalten

- Akzeptiert: `text/plain`
- Produziert: `text/plain` (Echo)
- Offline-fähig: Ja
- Export: Nein
- Bei Fehler: Gibt Input unverändert zurück

## Nutzung

Dieses Modul dient als Vorlage. Kopiere das Verzeichnis und passe `module.json` an.
