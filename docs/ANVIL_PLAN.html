RunResult — versiegelte Antworten

sealed class RunResult {
    data class Success(val artifacts: List<Artifact>) : RunResult()
    data class DegradedAtStep(val step: RunStep, val reason: String) : RunResult()
    data class BlockedAtGate(val gate: String, val condition: String) : RunResult()
    data class ModuleFailure(val moduleId: String, val cause: Throwable) : RunResult()
}

Zustands-Grammatik

STABLE
Vollständig funktionsfähig. Alle Checks grün.
DEGRADED
Eingeschränkt. Läuft, aber nicht voll — z.B. kein Cloud-Zugang.
BLOCKED
Wartet auf Bedingung. Gate nicht erfüllt.
FAILED
Harter Fehler. Eingriff nötig. Kill-Kriterium ausgelöst.

:core:contracts

Core Contracts

:core:contracts hat keine Dependencies außer Kotlin stdlib + kotlinx.serialization. Jedes Modul, das in Anvil läuft, implementiert ModuleSlotContract.

ModuleSlotContract — 7 Felder

interface ModuleSlotContract {
    val id:           ModuleId
    val version:      String                      // SemVer "1.0.0"
    val capabilities: List<ModuleCapability>
    val requires:     List<ModuleCapability>       // Abhängige Capabilities

    suspend fun boot(ctx: ModuleContext): BootResult
    suspend fun handle(step: RunStep):   StepResult
    fun qualityState(): QualityState              // nie fake-STABLE!
}

BellowsContract — LLM-Routing

interface BellowsContract {
    suspend fun route(request: ModelRequest): ModelResponse
    fun availableProviders(): List<ProviderInfo>
}

// ModelRequest — immer mit explizitem PrivacyMode
val request = ModelRequest(
    capability  = ModelCapability.CODE_PATCH,
    messages    = listOf(ChatMessage("user", "...")),
    privacyMode = PrivacyMode.LOCAL_ONLY,    // niemals Cloud-Fallback
    costCapUsd  = 0.05f,
    priority    = RequestPriority.INTERACTIVE
)

Serialisierungsregel: Alle Domain-Typen sind @Serializable. IDs sind immer @JvmInline value class mit String-Backing. Timestamps: ISO-8601 String, nie Long.

:core:domain

Domain-Modell

Das Domain-Modell folgt streng der Kette Workspace → Run → Artifact. Jede Entität hat eine typsichere ID und ISO-8601-Timestamps.

@Serializable
data class Workspace(
    val id:        WorkspaceId,
    val name:      String,
    val rootPath:  String,           // KILL: Änderungen außerhalb → FAILED
    val createdAt: String,           // ISO-8601 "2026-05-20T09:00:00Z"
    val state:     QualityState
)

@JvmInline @Serializable
value class WorkspaceId(val value: String)

@Serializable
data class Run(
    val id:          RunId,
    val workspaceId: WorkspaceId,
    val steps:       List<RunStep>,
    val result:      RunResult?,
    val createdAt:   String
)

@Serializable
data class Artifact(
    val id:          ArtifactId,
    val runId:       RunId,
    val type:        ArtifactType,
    val path:        String,         // relativ zu Workspace.rootPath
    val provenance:  String,         // Gate-Referenz, z.B. "Gate B3"
    val createdAt:   String
)

:core:quality

Quality Guard

Jedes Modul muss qualityState() korrekt implementieren. STABLE darf nur zurückgegeben werden, wenn tatsächlich geprüft wurde.

// RICHTIG:
override fun qualityState(): QualityState =
    if (isHealthy()) QualityState.STABLE else QualityState.DEGRADED

// FALSCH (nie tun — Kill-Kriterium):
override fun qualityState(): QualityState = QualityState.STABLE

Workspace-Safety — härtestes Kill-Kriterium

Jede Änderung außerhalb Workspace.rootPath → QualityState.FAILED — kein Silent-Fail, immer Exception. Dieses Kriterium schützt das Dateisystem des Nutzers.

:modules:bellows

Bellows — LLM-Router

Bellows ist der einzige Einstiegspunkt für alle LLM-Anfragen. Es verwaltet Provider-Ketten und erzwingt Privacy-Regeln.

Privacy — LOCAL_ONLY ist hart

// In BellowsRouter: LOCAL_ONLY blockiert Cloud-Provider
if (request.privacyMode == PrivacyMode.LOCAL_ONLY && !adapter.isLocal) continue

// Wenn kein lokales Modell verfügbar:
throw BellowsExhaustedException("No local provider available")
// Nie: null, leerer String, oder Cloud-Fallback!
PrivacyModeVerhalten
LOCAL_ONLYNur lokale Modelle. Cloud ist verboten. Kein Fallback.
CLOUD_ALLOWEDLokale Modelle bevorzugt, Cloud als Fallback erlaubt.

Knight ist der exklusive File-I/O-Layer in Anvil. Kein java.io.File in commonMain — nur Okio.

// FALSCH — verboten in commonMain:

Qualitätssicherung

Kill-Kriterien

Diese Kriterien lösen sofort QualityState.FAILED aus. Kein Modul darf diese Grenzen still überschreiten.

  • Änderung außerhalb Workspace.rootPath — schützt das Dateisystem des Nutzers
  • PrivacyMode.LOCAL_ONLY + Cloud-Request — Privacy-Versprechen gebrochen
  • Modul ohne ModuleSlotContract — kein unkontrolliertes Modul in Anvil
  • Commit ohne Gate-Referenz — Prozess-Kill (nicht Code-Kill)
  • @Suppress("all") oder Unterdrücken von Compiler-Warnungen
  • Roher String als ID (statt @JvmInline value class)
  • iOS-Target hinzufügen — explizit kein MVP-Scope
  • Hilt für DI einführen — Android-only, KMP-inkompatibel
  • Zirkuläre Abhängigkeiten zwischen Modulen

Regel: Bei Unsicherheit — stoppen, nicht raten. docs/KNOWN_DRIFT_RISKS.md lesen, Gate pausieren, Mensch fragen.

Governance

Agenten-Regeln

AgentDarfDarf nicht
Claude / Hyperagent Gates implementieren, PRs erstellen, Gradle-Dateien anlegen, Kotlin-Code für genehmigte Gates schreiben Eigene Gates definieren, Architektur-Entscheidungen treffen, Module ohne Contract anlegen
Codex / Copilot Code-Reviews, Refactoring innerhalb Gate-Scope, Bugfixes Gate-Reihenfolge ändern, neue Abhängigkeiten ohne Gate hinzufügen
Mensch (Christian) Alles —

Pflichtregeln für alle Agenten

  • Kein Commit ohne Gate-Referenz — Präfix: Gate XY: beschreibung
  • Kein Modul ohne Contract — ModuleSlotContract muss implementiert sein
  • Definition of Done prüfen — vor dem PR alle DoD-Punkte der Gate durchgehen
  • Tests oder Proof — jede Gate hat mindestens eine Verifikation
  • Aktive Dateien kennen — anvil-kmp/ ist der einzige Arbeitsbereich für Code
