# Gates — Übersicht

## Gate-System

Gates sind sequenziell, jede hat:
- **Ziel** — Was soll erreicht werden?
- **Aufgaben** — Konkrete Schritte
- **Definition of Done** — Wann ist die Gate erledigt?
- **Kill-Kriterien** — Wann abbrechen?
